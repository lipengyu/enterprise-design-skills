# AI Workspace Theme

适用：企业 Agent 平台、模型管理、Prompt/Skill 管理、工作流和运行监控。

- 视觉方向：Linear 的简洁交互 + Vercel 的技术工作台 + 企业后台信息架构。
- 采用“左侧资源导航 + 中央工作区 + 可选右侧详情面板”。
- Agent、模型、工具、Skill、Workflow 使用统一资源卡片和状态体系。
- 执行过程提供时间线：任务、步骤、工具调用、人工审批、结果。
- 状态至少包括：Draft、Ready、Running、Waiting Approval、Succeeded、Failed、Cancelled。
- 日志和工具调用默认折叠，支持按步骤展开；敏感参数脱敏。
- 高风险工具调用必须有明确授权和人工确认。
- 避免把所有管理功能包装成聊天窗口。
